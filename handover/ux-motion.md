# UI、输入与动效摘要

> 视觉方向已定为“制图工作台”；组件级细节由 Tasks 9–13 在该约束内实现。

## 布局与视觉

- ≥860 CSS px：约 62% 地图 + 38% 固定航海灰蓝题面；更窄时上下堆叠，操作行粘底，无横向滚动。
- 反馈在题面原位展开，不推动地图；提示在左，检查/继续在右。
- 测验隐藏答案标签；答对或二错揭示后显示；探索显示完整标签。
- 正误同时使用文字、图标、轮廓、填充和颜色；所有视觉值来自 token。

## 输入与暂停

- 非输入题：鼠标/数字键选择，Space 检查/继续。
- 输入题：Enter 提交/继续，Space 保留输入；H 只在非可编辑焦点请求提示。
- 地图单一 Tab 停靠点；方向键空间最近邻，Enter 选择；IME `isComposing` 优先。
- Esc：练习 ↔ 暂停；选项 Esc 先回暂停，再 Esc 恢复。失焦、最小化、休眠均暂停计时，回前台仍保持暂停。
- 返回主页不二次确认，但必须等待进行中的保存；未提交题不计分。

## 选项、声音与无障碍

选项仅有音效开关、`crisp/soft/minimal` 方案和 0–100 音量（默认 70）。五类声音事件：正确、错误、提示、揭示、完成；加载失败静默降级。素材必须原创，无背景音乐。

普通反馈 180–240ms，只动画高效属性；支持 `prefers-reduced-motion`。最低窗口 1024×700、200% 缩放仍可完成核心练习；所有快捷键有可点击等价路径与可见焦点。
