# 画面、交互、动画与声音上下文

> 权威范围：视觉语言、练习布局、标签、键鼠、暂停、声音、动效和无障碍。产品流程见 `product.md`。

## 视觉方向

采用已确认的“制图工作台”方向：浅色制图网格、清晰边界、克制印刷色和地图工具感。地图是视觉主角，UI 不复制 Duolingo 的主题、角色或页面结构。

练习页：

- 至少 860 CSS px 宽时地图主区约 62%，右侧固定题面约 38%。低于阈值时改为地图在上、题面在下；操作行粘底，可纵向滚动但无页面横向滚动。
- 右栏采用已确认的“航海灰蓝”冷色面板。
- 右栏底部操作行中提示按钮固定左侧，检查答案/继续固定右侧；按钮与面板及彼此使用高对比色。
- 反馈在右栏原位展开，不挤压或移动地图。
- 最低可用窗口 1024×700；200% 缩放仍可完成练习。

## 地图标签与状态

- 测验中隐藏会泄露答案的行政区名和城市名，保留必要河湖锚点。
- 答对或进入二次错误 `revealed` 状态后才揭示正确名称；首次错误重试不得泄露。探索模式可显示完整标签。
- 正误不只用红/绿：同时使用文字、图标、轮廓、填充和形状变化。
- 地图区域和城市点提供可见焦点、可读名称、选中状态和键盘路径。

## 键盘与鼠标

- 非输入题：鼠标/数字键选择；空格检查；反馈后空格继续。
- 输入题：Enter 提交；反馈后 Enter 继续；空格始终可输入。
- `H` 请求提示，但可编辑输入框聚焦时禁用；`1–4` 选择候选。
- 未选择答案时主操作禁用；按空格只强调待完成区域，不提交。
- 地图只有一个 Tab 停靠点，方向键按实体质心进行空间最近邻导航；Enter 选择当前区域/点位，空格完成主操作。
- 输入法 `isComposing` 时快捷键不截获按键；Esc 先交给 IME。
- 所有快捷键都有可点击等价控件；原生对话框或无关输入聚焦时禁用全局快捷键。

## 暂停与选项

按一次 `Esc` 打开已确认的居中暂停卡，背景变暗并轻微模糊；再次按 `Esc` 等同继续。菜单：继续、选项、返回主菜单。

暂停、窗口失焦、最小化和系统休眠冻结反应计时；返回前台仍显示暂停卡，主动继续后恢复计时。

进入选项后按 `Esc` 先返回暂停卡并保持暂停，再按一次恢复。返回主菜单无需二次确认：已提交题逐题保存，当前未提交题不计分，会话可继续。

选项只含：

- 音效开关（默认开启）。
- 音效方案下拉：清脆（默认）、柔和、极简。
- 音量滑轨：默认 70%，范围 0–100，步长 1。

没有学习语言选项。

## 动画与声音

参考 Duolingo 的 responsiveness：低延迟、按下回弹、正误同步、快速继续；不复制其动画或声音资产。

- 普通反馈 180–240ms，以 `transform`、`opacity`、`fill`、`stroke` 为主。
- 错误可轻微震动，正确短促确认；强庆祝仅用于会话完成或阶段提升。
- 三套音效必须为项目原创；常用反馈小于 250ms，完成音效小于 900ms。
- 首次正确、首次错误、提示、二次揭示和会话完成分别有声音；重测答对复用正确音效，阶段提升不叠加声音。
- 切换音效方案立即试听，静音时不试听；音频失败自动降级为无声，不阻断练习。
- 无背景音乐、无地名语音朗读。
- 支持 `prefers-reduced-motion`；声音与动效不承担唯一语义。

## 组件风格规则

- 使用设计 token 管理颜色、间距、圆角、阴影、时长和缓动；组件内不散落魔法值。
- 题干、操作和纠错的视觉层级高于装饰；坐标网和河湖降低对比度。
- 控件文字使用明确动作：“检查答案”“继续”“提示”“返回主菜单”。
- 空状态与错误必须说明下一步，不使用模糊“发生错误”。
