# 决策与变更权限

> 产品、算法、内容、UI 和架构的当前规则由各专题维护；本页只说明执行权限与已淘汰方向。

## 当前有效

- 用户已批准完整规格，并授权不扩张范围的实现细节采用推荐方案，无需逐项追问。
- 16 任务计划按依赖顺序执行；跨任务契约已在提交 `34ca6a0` 冻结。
- 使用 subagent-driven development：任务实现 → 独立审查 → 最多五轮修复复审 → 账本记录。
- 当前分支为 `codex/user-test-mvp`。个人测试包可标记 `development-only`；这不代表公开发行批准。
- 新功能、范围扩张、公开发行承诺或推翻硬约束仍需用户明确授权。
- 用户于 2026-08-28 明确扩展第一版范围：必须提供会检查并自动安装运行依赖的安装包，并支持从本 GitHub 仓库 Releases 更新。此决定覆盖旧规格中“自动更新不在范围”的表述；更新包必须签名，私钥不得入库。
