# 内容与地图摘要

> 只维护内容口径、语言、包结构与合规边界；实际 TypeScript 契约以 `src/content/` 和实施计划“Frozen content and map contract”为准。

## 固定包与语言

- `cn-provincial-divisions`：34 个省级行政区，主要答案语言 `zh`。
- `cn-shanghai-districts`：16 个上海行政区，主要答案语言 `zh`。
- `us-states`：50 州，主要答案语言 `en`。

认识/揭示显示中英文；输入接受包内声明的规范中英文名、别名和缩写，不自动接受拼音。无真实关系、几何或点位时不得生成对应题。

## 版本化包

每包只读包含 `manifest.json`、`entities.json`、`map.topojson`、`sources.json`：

- manifest：版本、稳定包 ID、主要语言、能力、数量、视口、三文件 SHA-256、`distributionStatus`。
- entities：稳定 ID、类型/父级、双语名/别名、首府关系、权威坐标、可用能力。
- topology：行政区、可选城市点与河湖；点坐标若重复保存，必须与 entity 坐标在 `1e-6` 度内一致。
- sources：机构、URL、日期、许可、哈希、CRS、处理步骤、简化/量化和可选审图标识。开发包可为空；公开发行前必须由人工判断是否需要并补齐有效标识或明确不适用依据。

包校验失败时整包隔离，不返回部分实体。加载器与几何/哈希执行分别在 Tasks 3、14 完成。

## 数据与合规

中国/上海从官方标准地图或明确可公开使用来源开始，保留原始文件和每一步哈希；美国优先 Census 边界与官方/公共领域州府数据。用户附件不得作为数据资产。

个人测试包可标记 `development-only`；面向中国大陆公开发行前仍需人工实际成图比对、法规判断、审图号/标准地图标识与具名签字。自动测试不能替代该门禁。实体总数仍为 34/16/50；缺失关系只禁用对应题型，不删除实体。

改名/边界微调保持稳定 ID 和进度；拆分/合并/层级变化归档旧记录，新实体从 `new` 开始。
