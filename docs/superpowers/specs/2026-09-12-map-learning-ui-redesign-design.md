# 地图学习 UI 重构设计

## 目标

将首页和练习页改造成设计图所示的明亮、游戏化地理课堂，同时保持现有离线内容、学习状态机、地图选择和备份功能。

## 范围

- 将 `地图学习背景图.png` 作为本地页面背景资源；使用半透明遮罩保证可读性。
- 首页提供品牌导航、学习卡片、真实掌握度数据、更新检查和数据管理入口。
- 练习页提供共用导航、地图卡、题目卡、真实进度、提示和暂停/设置入口。
- 统计、知识库和帮助显示为清楚的后续功能入口，不制造虚假的统计或知识内容。
- 保留地图投影、键盘操作、中文输入保护、保存失败状态和 reduced-motion 行为。

## 视觉系统

- 墨蓝 `#071B4B` 用于标题和主要文字。
- 学习绿 `#08A83A` 与亮绿 `#32C84B` 用于主操作和进度。
- 天空蓝 `#A9DDF7`、云白 `#F8FCFF` 用于背景和卡面。
- 提示黄 `#FFC400` 用于有限的强调装饰。
- 使用 Windows 已有中文字体栈，不下载在线字体。
- 图标采用原创内联 SVG；不从设计截图裁剪图标。

## 组件边界

- `AppHeader`：品牌、主导航、可用的页面操作和后续入口状态。
- `PackCard`：真实内容包数据、装饰性地图缩略图和开始练习操作。
- `PracticeScreen`：所有题型共用的卡式练习布局；不改变 reducer 或持久化契约。
- `MapViewport`：保留真实 SVG 地图及无障碍选择；增加可点击的缩放/复位控件。

## 响应式与素材

背景图为 1672×941；宽屏采用 `cover`，窄屏裁切并加大遮罩。页面主体不随背景缩放。大于 900 CSS px 使用地图与题目并排，小于该宽度改为纵向；装饰卡组在窄屏隐藏。

## 验收

- 现有首页操作仍能进入对应学习、探索和数据管理流程。
- 练习中的地图、选择和文字输入题仍能完整进入总结页。
- `1024×700`、`1536×1024`、`1672×941`、窄屏与 200% 缩放无横向滚动。
- 键盘地图操作、可见焦点和 reduced motion 仍然有效。
