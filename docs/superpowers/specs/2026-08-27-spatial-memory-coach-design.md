# 空间记忆教练设计规格

> 日期：2026-08-27<br>
> 状态：已批准，可进入开发计划<br>
> 批准依据：用户已逐项确认主要产品和交互决策，并于 2026-08-27 授权其余问题采用推荐方案。<br>
> 工作名：空间记忆教练（Spatial Memory Coach）

## 1. 产品目标

构建一款可安装在 Windows 与 macOS 上的离线桌面应用，通过地图上的主动回忆、即时纠错和自适应复习，帮助用户建立地点名称、行政区域、城市点位和首府关系之间的双向空间记忆。

首版首先服务单个本地学习者，同时保留未来公开发行、增加国家和增加地点知识模块的扩展边界。产品不是地图百科、在线地图或游戏化课程树，也不把闪卡作为唯一学习形式。

成功标准：

- 用户无需账号或网络即可完成选择内容包、学习、练习、探索、查看进度和备份。
- 每次智能练习默认 12 题，约 5–10 分钟，系统能优先复习到期、薄弱和易忘地点。
- 五种核心题型均在同一地图练习框架中流畅工作，错误能够提示、二次作答和延迟重测。
- Windows 10 22H2、Windows 11、macOS 12 及以上版本可安装运行；macOS 同时产出 arm64 与 x86_64 构建。
- 三个首发内容包通过数量、关系、双语名称、几何和来源元数据校验。
- 中国地图内容在开发阶段保留完整来源与处理链；公开分发前必须通过独立人工合规检查，不以自动校验代替审图。

## 2. 方案比较与选择

### 2.1 产品形态

选择“自适应空间记忆教练”。它把地图定位、名称识别、首府关联和城市点位作为不同能力分别跟踪，并用短会话调度。相比固定闪卡，它能训练空间回忆；相比完整游戏化课程，它更适合个人离线工具且首版范围可控。

未选择的方案：

- 固定地图闪卡：实现最快，但无法可靠训练名称到位置的双向提取，也不能区分不同技能。
- 完整课程树与奖励系统：可提高表层参与度，但会引入生命值、任务、经济系统和大量内容运营，不符合首版目标。

### 2.2 桌面技术

选择 Tauri 2 + React + TypeScript + SQLite + 本地 SVG/TopoJSON 的模块化单体。Tauri 在 Windows 使用 WebView2，在 macOS 使用 WKWebView；Rust 只承担桌面与持久化边界，学习规则留在可测试的 TypeScript 域层。

未选择的方案：

- Electron：生态成熟但运行时与安装体积更重，本项目不需要完整 Chromium 隔离能力。
- Windows/macOS 双原生：平台体验上限高，但会复制学习规则、地图交互和测试成本。
- 在线网站/PWA：难以满足明确的本地安装、稳定离线、SQLite 备份和桌面文件工作流。

## 3. 首发范围

### 3.1 内容包

首发三个内容包始终可以自由选择，不设置等级解锁：

1. `cn-provincial-divisions`：中国 34 个省级行政区，以及内容数据实际提供的省会、首府或行政中心关联和点位。
2. `cn-shanghai-districts`：上海市 16 个行政区。
3. `us-states`：美国 50 个州及州府关联和点位。

中国内容包采用国内官方口径：23 个省（包含台湾）、5 个自治区、4 个直辖市和 2 个特别行政区。香港、澳门显示为特别行政区；港澳台不添加特殊课程、额外说明或虚构首府关系。

主要河流与湖泊是可切换的背景定位锚点，不参与首版测验和掌握度。地点详情首版不展示人口、历史、经济或图片，但内容 schema 和详情面板允许未来添加经过策划的可选知识模块。

### 3.2 首发题型

1. 名称 → 点击行政区域（`locate_region`）。
2. 高亮行政区域 → 识别名称（`identify_region`）。
3. 省级行政区/州 → 省会、首府或州府关联（`associate_capital`）。
4. 城市名 → 选择地图点位（`locate_place`）。
5. 城市点位 → 识别城市名（`identify_place`）。

只有实体具备相应关系与几何时才可生成题目。首版不做空白地图自由落针距离评分、方向推理、相邻关系题或河湖课程。

### 3.3 明确非目标

- 账号、云同步、多学习者切换、社交、排行榜、生命值、连续签到、每日任务、货币和订阅。
- 在线瓦片、定位、导航、用户上传标注、第三方内容包导入、内容市场和应用内地图编辑器。
- 应用商店上架、正式签名、公证、自动更新和公开发行承诺。
- 地名发音、背景音乐和复制第三方产品的音效或动画素材。

## 4. 核心用户流程

### 4.1 首次进入内容包

用户首次从内容包卡片进入“智能练习”时，可进行一次可跳过的 12 题快速摸底。摸底覆盖不同地点和能力，只用于初始化掌握度，不计分或排名。跳过则所有地点从 `new` 状态开始。自定义练习和探索地图不会被摸底拦截。

新地点第一次进入智能练习时先出现短暂认识步骤：高亮位置，显示中英文名称及存在的首府关联，用户主动继续；同一会话稍后再以主动回忆题重现。认识步骤不计入 12 道题，进度单独显示为“认识 n/m”，其游标与题目游标一起持久化。默认智能会话最多引入 4 个新地点；当没有足够的到期或薄弱内容时可增加至 6 个。

### 4.2 智能练习

默认会话固定 12 题，不倒计时。调度顺序：

1. 已到期复习。
2. 薄弱能力。
3. 易忘地点，最多占会话的 25%。
4. 4–6 个新地点。
5. 用于保持已掌握能力的少量混合题。

五种题型按“地点 × 能力”薄弱程度选择，不要求平均分配；单一题型不超过本次会话的 50%。12 题是基础题数：需要延迟重测时可追加至最多 15 题；如果会话剩余空间无法保证 3–5 道间隔，则把该重测债务设为立即到期并放到下一次智能会话最前，不缩短间隔也不无限延长本轮。用户中断时每道已提交题都已保存；一天内重新打开可继续原题序列，超过一天则关闭旧序列并根据最新进度重新生成，已产生的掌握变化不丢失。

### 4.3 自定义练习

用户可选择内容包、一个或多个地点、题型、学习状态（包括“易忘”）和题量。自定义练习仍更新真实掌握度，但不受智能练习的新地点数量限制。

### 4.4 探索地图

探索不计分。地图支持缩放、平移、悬停、键盘焦点、标签和河湖图层。点击地点只显示与学习直接相关的双语名称、类型、父级、首府关联、各能力状态、易忘标记和“练习这个地点”。未来知识模块通过详情面板扩展插槽增加，首版不显示空入口。

### 4.5 会话总结

结束页显示答对率、独立答对数、提示次数、新认识地点、掌握度变化以及新增或解除的易忘标记。主要操作为“再练薄弱项”和“返回主菜单”；不显示排名、经验值或惩罚性分数。

## 5. 作答、提示与语言

### 5.1 作答状态机

每道题依次处于 `presenting`、`answering`、`first_retry`、`revealed`、`completed`。地图题先选择对象，再显式提交，避免小区域误触。行政区定位和城市点位定位始终是地图选择；区域识别、首府关联和城市识别在 `new/learning` 阶段使用四选一，在 `weak` 及以上阶段优先使用文字输入。

- 首次答错：标明误选对象，给出最弱但有用的题型提示，允许重试。
- 第二次答错：揭示正确答案，并在 3–5 道其他题后插入变式重测。
- 主动提示：允许在作答前使用；提示后答对不升级掌握度，并安排稍后重测。
- 正确反馈：区域或点位立即确认，右栏显示答案和简短说明，布局不移动。只有答对或进入 `revealed` 状态才显示正确名称；首次错误重试阶段不得泄露答案标签。

题型提示自动选择，不要求用户挑选提示类型：

- 地图定位题：目标相对误选位置的大致方向，不高亮正确对象。
- 文字识别题：给首字或首字母。
- 选择题：排除一个可信干扰项。

### 5.2 答案归一化

输入判定忽略大小写、首尾和重复空格、常见标点差异，并允许省略“省、自治区、市、区、州”等不影响唯一性的类型后缀。接受内容包声明的中文名、英文名、常见简称和英文缩写；不自动把拼音视为中文名称答案。

应用没有学习语言设置。每个内容包显式声明 `primaryAnswerLanguage`：英语为母语或官方语言的国家/地区通常使用 `en`，其他内容通常使用 `zh`；复杂多语地区由内容作者明确选择，不在运行时推断。题干目标名、四选一候选和测验标签只使用包的主要答案语言；认识和揭示阶段以“主要语言在前、另一语言在后”显示双语；输入题同时接受规范中文与英文答案。首发中国与上海包使用中文为主要答案语言，美国包使用英文。

## 6. 学习模型

### 6.1 掌握记录

自然主键是 `(learnerId, packId, entityId, skill)`。首版只有一个默认学习者，但保留 `learnerId` 以支持未来多档案。

阶段采用可解释模型而不是 FSRS：

| 阶段 | 默认下次复习 |
|---|---:|
| `new` | 本次会话先认识 |
| `learning` | 10 分钟 |
| `weak` | 1 天 |
| `familiar` | 3 天 |
| `solid` | 7 天 |
| `mastered` | 21 天；之后成功可扩展至最多 90 天 |

首次独立答对可以晋升一级；使用提示、重试后答对或揭示后跟答不晋升。首次错误至少保持原阶段并缩短间隔；完全失败时降一级且安排本会话重测。反应时间只在正确率相同的候选间用于排序，学习者较慢不会被扣分。

### 6.2 易忘标记

“易忘”独立于“薄弱”。某能力达到 `familiar` 后，如果最近 30 天内出现至少两次计划复习失败，则自动标记 `fragile`。完成三次相隔至少 24 小时的独立正确复习后自动解除。任何地点存在一个 `fragile` 能力时，地图和地点详情显示聚合标记；点击后展示具体能力。

## 7. 视觉与交互

### 7.1 视觉语言

采用“制图工作台”方向：浅色制图网格、清晰行政边界、克制的印刷色和地图工具感。练习页在至少 860 CSS px 宽时地图约占 62%，右侧固定题面约占 38%。右栏采用“航海灰蓝”冷色面板；右栏底部操作行的提示按钮位于左侧，检查/继续位于右侧，两者与面板及彼此保持高对比。低于 860 CSS px（包括 1024×700 下 200% 缩放）时改为地图在上、题面在下的纵向布局，操作行粘在可视区域底部，允许纵向滚动但不出现页面横向滚动。

测验时隐藏会泄露答案的行政区和城市标签，但保留必要河湖锚点；答对或二次错误进入 `revealed` 状态后才揭示正确名称，首次错误重试不揭示。探索地图可显示完整标签。

### 7.2 动画与声音

借鉴 Duolingo 的低延迟、按下回弹、正误同步和连续作答节奏，不复制其配色、角色、页面结构、声音文件或动画资产。普通答题只使用短促微动效；较强庆祝保留给会话完成或阶段提升。支持 `prefers-reduced-motion`。

音效默认开启、默认音量 70%，滑轨范围 0–100、步长 1。首版提供三套原创方案：清脆（默认）、柔和、极简。选中方案时即时试听；静音时不试听。声音事件为首次正确、首次错误、提示、二次揭示和会话完成；延迟重测答对复用首次正确音效，阶段提升不叠加额外声音。音量滑轨和音效开关即时生效并持久化。无背景音乐，声音不是正误的唯一反馈。

### 7.3 键鼠规则

- 非输入题：鼠标/数字键选择，空格键检查；反馈阶段空格键继续。
- 输入题：Enter 提交；反馈阶段 Enter 继续，空格保留给文字输入。
- `H`：请求提示，但任何可编辑输入框聚焦时禁用。
- `1–4`：选择候选项。
- `Esc`：练习中打开居中暂停卡，再按一次等同“继续”；输入法 `isComposing` 时先交给 IME，不打开暂停。
- 选项子页按 `Esc` 返回暂停卡且保持暂停，再按一次恢复练习。

未选择答案时主操作禁用；按空格只强调尚未完成的选择区域，不提交空答案。地图作为单一 Tab 停靠点，方向键根据实体质心寻找对应方向最近的区域/点位，Enter 选择当前焦点，空格执行主操作；另提供可访问名称与当前选择朗读。关键功能均提供可点击控件，快捷键不是唯一操作路径。

### 7.4 暂停与选项

暂停卡背景变暗并轻微模糊，包含继续、选项、返回主菜单。暂停、窗口失焦、最小化和系统休眠期间冻结反应计时；从后台返回时保持暂停卡，用户主动继续后才恢复计时。返回主菜单无需二次确认：完成题已逐题保存，当前未提交题不计分，会话保持可恢复。

选项只包含音效开关、音效方案和音量；不包含学习语言。设置变化立即预览并保存。

## 8. 架构与数据流

### 8.1 模块边界

- `app`：启动、页面状态、依赖装配、全局错误边界。
- `content`：内容 schema、校验、载入、版本迁移和来源元数据。
- `map`：投影、SVG 图层、命中、视口、标签和可访问性。
- `learning`：能力、掌握度、易忘、调度、答案归一化和提示。
- `practice`：会话、题目状态机、智能/自定义/摸底和总结。
- `explore`：探索地图和地点学习详情。
- `persistence`：repository 接口、SQLite 适配、迁移和备份。
- `desktop`：Tauri 命令、资源文件、原生文件对话框和打包。
- `audio`：音效方案、预加载、音量和 reduced-motion 无关的声音设置。

模块只通过显式类型和接口通信。地图发出选择和视口事件，不认识题目正确答案；React 页面只组合状态和视图，不实现掌握算法或 SQL。

### 8.2 数据流

1. Tauri 启动并迁移 SQLite，读取设置、内容清单和未完成会话。
2. TypeScript 内容层校验资源包，隔离无效包并生成可用能力索引。
3. 学习调度器从 repository 快照生成不可变 `PracticeSession`。
4. 题目状态机接收用户动作，学习域函数生成 `AttemptOutcome` 与下一掌握状态。
5. UI 立即显示反馈并同步启动保存；持久化适配器在允许继续、返回主菜单或关闭会话前用事务保存 attempt、mastery 和 session cursor。这里“已提交题已保存”指事务成功后的状态；若事务完成前进程崩溃，重启后恢复同一题，不能假装该 attempt 已提交。
6. 会话完成后由事件和掌握快照生成总结。

### 8.3 SQLite 与备份

数据库至少包含 `learner`、`mastery`、`attempt_event`、`practice_session`、`app_setting`、`content_migration` 和 `schema_migration`。多表答题更新必须处于单一事务中，迁移只能向前且可在空库重复执行。

备份从首页右上角“数据管理”进入。导出打开保存对话框并在成功后显示文件名；导入先选择文件、只读检查并展示导出日期、学习者和记录数量，再选择默认“合并”或高级“完全替换”。备份使用版本化 `.geolearn-backup` ZIP 容器，包含 manifest、进度事件/掌握快照、未完成会话和设置，不重复打包内置地图。导入在完整校验后自动生成安全快照：

- 默认“合并”：同一地点与能力保留更新时间较新的有效记录，attempt 以稳定 ID 去重。
- “完全替换”：明确警告后在单一事务内替换学习数据和设置。
- 损坏或版本不兼容：不写入数据库，保留当前数据并显示可操作错误。

内容包改名或边界微调时稳定 ID 不变并保留进度；拆分、合并或层级变化时归档旧记录，新实体从 `new` 开始，更新说明列出变化。

## 9. 内容包与地图合规

每个包包含：

- `manifest.json`：schema/content 版本、稳定 ID、主要答题语言、默认视口、能力声明和校验值。
- `entities.json`：稳定实体 ID、类型、父子关系、中英文名称、别名、首府关系和可用题型。
- `map.topojson`：行政区多边形、城市点、可选河湖线。
- `sources.json`：来源机构、URL、发布日期、许可、坐标系、处理步骤、简化参数及审图/标准地图标识。

加载校验包括版本、ID 唯一性、引用完整性、名称、实体数量、点位落界、拓扑有效性、能力可生成性和文件校验值。无效包整体隔离，不允许部分载入污染进度。

中国地图管线必须从官方标准地图或具有明确公开使用资格的来源开始，保存原始文件哈希和每一步变换。标准地图服务系统明确指出，对标准地图进行放大、缩小、裁切等编辑后公开使用，仍可能需要送审；因此开发验证通过不代表取得公开发行批准。任何面向中国大陆的公开版本都必须设置“实际成图人工检查 + 法定审核判断 + 审图号/标准地图标识核验”的发布门禁。

## 10. 错误处理

- 内容包错误：隔离单个包，首页显示具体校验失败项，其他包可继续使用。
- 数据库迁移错误：停止进入练习，保留数据库副本并提供打开备份目录的操作。
- 答题保存错误：保持当前反馈页，不允许无提示进入下一题；重试成功后再推进。
- 备份导入错误：校验阶段失败不触发写入；事务失败回滚并保留安全快照。
- 音频加载错误：降级为无声反馈，不阻断学习，并在选项中标记该方案不可用。
- 未捕获 UI 错误：全局错误边界显示重启应用和导出诊断信息，不泄露个人路径或内容。

## 11. 可访问性与性能

- 最低可用窗口 1024×700；200% 缩放下核心练习仍可完成。
- 所有控件有可见焦点；地图提供单一 Tab 入口、方向键空间导航、可读名称、角色和选中状态。
- 正误不只依赖红绿；同时使用文字、图标、边框和形状变化。
- 冷启动在基准设备约 2 秒内可操作；答案反馈 100ms 内出现；题目切换 200ms 内完成；地图拖放与缩放目标 60fps。
- 地图几何预处理和音效预加载不在答题提交路径执行；动画优先使用 `transform`、`opacity`、`fill` 和 `stroke`。

## 12. 测试与发布门槛

- 单元：内容校验、答案归一化、提示、阶段迁移、易忘标记、调度、公平性限制和备份合并。
- 组件：五类题、认识步骤、首次错误/二次揭示、快捷键、暂停栈、音效设置和 reduced-motion。
- 端到端：首页 → 摸底/智能练习 → 错误重测 → 总结 → 重启恢复；自定义；探索；备份导出导入。
- 数据：34 个中国省级行政区、16 个上海行政区、50 个美国州；关系、名称、点位、几何和来源元数据。
- 跨平台：Windows 10 22H2、Windows 11、macOS 12+ arm64/x86_64 的安装、首次启动、中文输入、文件对话框和数据库创建。
- 发布前：中国地图实际成图与法定审核门禁；第三方许可证清单；无网络依赖验证；备份恢复演练。
